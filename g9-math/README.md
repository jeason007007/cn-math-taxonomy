# 初三数学 · 盲点诊断

给初三（九年级）孩子用的数学盲点诊断工具。纸笔测试 + 跨年级根因追溯。

**出卷 → 打印 → 做卷 → 批改 → 找盲点 → 讲解 → 新卷**，一个闭环。

---

## 怎么用

直接双击 `index.html` 就能用，不需要装任何东西、不联网。

> 如果浏览器拦了本地文件，也可以起个本地服务：
> ```
> python -m http.server 8000
> ```
> 然后打开 http://localhost:8000

### 一次完整循环（约 40 分钟）

1. **出卷**（`paper.html`）
   选范围、题量、难度，点「生成试卷」。
   打印两份：**学生卷**给孩子做，**答案卷**你自己批改用（另起一页，分开拿）。

2. **做卷**
   纸笔作答。25 道题建议 30 分钟。

3. **批改**（`grade.html`）
   默认全部算对，只把做错的题点成「×」。答案和解析就在题下面，照着判。

4. **看盲点报告**（`report.html`）
   系统会沿先修边往上追，给出**根因链**——孩子错的可能是九年级的二次函数，
   但真正的坑在八年级的一次函数，甚至小学的正比例。
   标红的那一环最可疑，同时标出「不补会影响后面几个知识点」。

5. **打印讲解卡**（`teach.html`）
   每个盲点一张卡：定义、掌握标准、先修链、典型例题、本次错题回顾、同类练习。
   A4 一页一个，可以剪下来贴错题本。

6. **出新卷**
   报告页底部有「出根因验证卷」——只考那些可疑的根因点。
   如果还错，说明判断对了；如果对了，说明问题就在九年级本身。

## 数据基础

来自开源项目 [cn-math-taxonomy](https://github.com/xiaoyang111222/cn-math-taxonomy)（CC BY-NC 4.0），
对齐《义务教育数学课程标准（2022 年版）》与人教版教材。

| 项 | 数量 |
|---|---|
| 初三知识点 | 82（九上 49 + 九下 33） |
| 先修闭包 | 376（含小学 135、七 88、八 71） |
| 先修边 | 632 |
| 选择填空 | 363，每题带答案和解析 |
| 解答题 | **55**，每题带分值、完整解题过程和答题空间 |

九上：一元二次方程、二次函数、反比例函数、旋转、圆、直线与圆的位置关系
九下：相似、锐角三角函数、投影与视图、随机事件的概率

> **解答题是自己写的**（不在上游数据里），覆盖 34 个知识点，按山东中考风格：
> 解方程、判别式讨论、根与系数、增长率与利润、二次函数最值、圆的计算与切线证明、
> 相似证明、解直角三角形、概率树状图，以及一道二次函数与面积结合的压轴题。
> 答案已逐题手工核算，但仍建议家长过一眼。

## 答题空间

试卷按题型留不同空间，打印出来直接在上面写：

- **选择题**：题干后带「（　　）」，写字母
- **填空题**：题目下方一条横线，线与下一题之间有足够间隔
- **解答题**：独立一页起排，每题一个大方框（120–300 pt，按题目难度给），
  标题标出该题分值

源仓库更新后：

```
python build/bundle.py --src ../cn-math-taxonomy-main --out data/bundle.js
```

## 数据备份

首页底部有「导出数据备份」，存成一个 JSON。
换电脑或换浏览器时用「导入备份」恢复。所有记录只存在本机浏览器里，不上传任何地方。

## 已知限制

1. **选择填空题是 AI 生成、未经教师审核。** 答案建议家长扫一眼再给孩子用。
2. **解答题是自编的**，已逐题核算过答案，但同样建议家长先看一遍解题过程。
3. **每个知识点 4–5 道客观题**，连续做 5 张卷后会开始重复（解答题共 55 道，够撑 18 张卷）。
4. **根因推断是假设**，不是结论。必须靠下一张卷验证，别直接当成诊断书。
5. **教材目录与课标正文**在源数据里大量标「待核」，尤其 2024 年新教材改版后。
