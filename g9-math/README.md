# 初三数学 · 盲点诊断

给初三（九年级）孩子用的数学薄弱点诊断工具。**手机上直接做题**，或者打印出来做，
交卷后自动找出没打牢的地方，并沿着知识链往回追——错的可能是九年级的二次函数，
但真正的坑常常在八年级甚至小学。

**做题 → 判分 → 找薄弱点 → 讲解 → 新卷**，一个闭环。

---

## 打开方式

**电脑上**：直接双击 `index.html`，不用装任何东西。

**手机上**：双击 `启动.bat`，电脑会显示一个 `http://192.168.x.x:8000` 的地址，
手机连上同一个 WiFi 后在浏览器里输入这个地址即可。打开后点「添加到主屏幕」，以后点图标就能用。

---

## 两种用法

### 一、手机上直接做（不用打印，推荐日常用）

打开页面 → 点顶部导航的「做题」→ 选 12 道题 → 点选项或填答案 → 交卷。

马上出结果：每题对错、正确答案、解析，以及这次暴露了哪几个薄弱点。
错题会自动记进档案，下一张卷会重点考这些地方。

适合：每天 15 分钟，碎片时间。

### 二、打印出来做（要写过程，周末用）

打开「出卷」→ 选范围、题量、难度 → 生成 A4 试卷 → 打印两份：

- **学生卷**给孩子，解答题独立起页，每题留一大块答题空间
- **答案卷**自己拿着批改，答案另起一页，别一起给孩子

做完回来点「批改」，默认全部算对，只把错的点成「×」，提交后出分析。

适合：需要写解题过程的解答题、模拟考试。

### 手机上怎么打印

手机打印需要 AirPrint 打印机。家里没有的话，出卷页会显示当前网址，
点「发送到电脑」用 AirDrop/微信发到电脑，在电脑浏览器里打开同一个网址再打印，A4 格式最准。

### 三种模式

| 模式 | 出什么题 | 什么时候能用 |
|---|---|---|
| 常规卷 | 按范围均匀出，历史盲点加权 | 一直能用 |
| 综合卷（含根因探测） | 约 30% 考疑似根因点，其余按范围 | 一直能用。没测过时，那 30% 改考七、八年级的相关先修点 |
| 根因验证卷 | 只考疑似根因点，有几个点出几道题 | 要先有一张批改过的卷，系统才知道该验证哪些点 |

「根因验证卷」没有诊断数据就无从出题，所以会标成「需先测一次」并置灰。
它仍然可点，点一下会说明原因——不做成点了毫无反应的那种死按钮。

### 卷面构成

25 道题的卷子大约是 **12 选择 + 10 填空 + 3 解答**，跟中考卷的比例接近。
选择题占比是被单独约束住的：如果只按「难度就近取题」，题库里填空题更多，
一张卷会几乎全是填空，不像卷子。约 1/3 的题带图。

## 一次完整循环

1. **做题**：手机上 12 道，或打印 25 道
2. **判分**：手机自动判；纸卷点「×」
3. **看报告**：每章正确率、直接错的知识点、往上追的根因链
4. **看讲解**：每个薄弱点一张卡——定义、掌握标准、先修链、本次错题、例题、同类练习
5. **出新卷**：可以专门出「根因验证卷」，只考那些可疑的根因点。
   还错说明判断对了；对了说明问题就在九年级本身。

对齐《义务教育数学课程标准（2022 年版）》与人教版教材。

| 项 | 数量 |
|---|---|
| 初三知识点 | 82（九上 49 + 九下 33） |
| 先修闭包 | 376（含小学 135、七 88、八 71） |
| 先修边 | 632 |
| 选择填空 | 363，每题带答案和解析 |
| 解答题 | **55**，每题带分值、完整解题过程和答题空间 |

九上：一元二次方程、二次函数、反比例函数、旋转、圆、直线与圆的位置关系
九下：相似、锐角三角函数、投影与视图、随机事件的概率

> **解答题是自己写的**（不在上游数据里），覆盖 34 个知识点，按山东中考风格：
> 解方程、判别式讨论、根与系数、增长率与利润、二次函数最值、圆的计算与切线证明、
> 相似证明、解直角三角形、概率树状图，以及一道二次函数与面积结合的压轴题。
> 答案已逐题手工核算，但仍建议家长过一眼。

## 手机判分的容错

填空题答案比对不看写法，只看数值：

- `1/2` 和 `0.5` 都算对
- `1，-5，6`、`1,-5,6`、`-5, 1, 6` 都算对（顺序、全角半角、空格都不计较）
- 多写或少写一个数才算错

宁可漏判「错」，也不把「对」判成「错」——诊断工具最怕制造假盲点，
孩子明明会却因为写法不同被记一笔，后面就会浪费时间去补一个不存在的洞。

## 答题空间

试卷按题型留不同空间，打印出来直接在上面写：

- **选择题**：题干后带「（　　）」，写字母
- **填空题**：题目下方一条横线，线与下一题之间有足够间隔
- **解答题**：独立一页起排，每题一个大方框（120–300 pt，按题目难度给），标题标出该题分值

## 题图

上游题库是纯文字的，1673 道题一个图形字段都没有，题干里连「如图」都不出现。
中考卷里圆、相似、旋转、解直角三角形这些题几乎都带图，所以图全部是自己补的。

- 图是**内联 SVG**，不是图片文件：离线能用、打印不糊、任意放大不虚
- 参数化生成：题目给的数字（半径、角度、边长）直接进函数算坐标，图与题干不会对不上
- 共 **131 张**：20 张挂在自编解答题上，111 张挂在客观题上
- 图里只标**已知量**，要求的那一项一律标「?」——题图不能替孩子把答案算出来
- 纸张上按 92 mm 宽排版，`page-break-inside: avoid`，不会跨页被劈开
- 手机做题页、答案卷的逐题解析里也都会显示同一张图

覆盖范围：

| 批 | 张数 | 内容 |
|---|---|---|
| 解答题 | 20 | 垂径定理、圆周角、切线长、内切圆、外接圆、正六边形、相似判定、旋转、正方形半角、抛物线、反比例、拱桥、仰角、坡度、转盘 |
| 客观题 | 111 | 圆周角定理、直径所对圆周角、圆内接四边形、垂径定理、两条平行弦、弧长与扇形面积、圆锥与三视图、坡度与坡角、仰角与俯角、切线性质、切线长、直线与圆、内切圆与外接圆、抛物线族、反比例函数中的面积、原点对称、旋转、位似、正方形半角、相似判定、斜列车位、扇形统计图 |

初三客观题共 361 道，其中含几何/图象关键词的约 175 道，逐条读题后筛出真正非图不可的 111 道。
剩下的多是解方程、判别式、增长率、概率这类本来就该用纯文字出的题——中考卷上它们也没有图。

```bash
python build/make_figs.py --preview       # 解答题图，输出 figs-preview.html
python build/make_figs_obj.py --preview   # 客观题图，输出 obj-figs-preview.html
python build/bundle.py --src ../cn-math-taxonomy-main --out data/bundle.js   # 合进数据包
```

`node tests/test_quiz.js` 里有断言：题图必须是带 viewBox 的 `<svg>`、不能含脚本或事件属性、
带图的题必须仍有答案和解析。

## 数据存在哪

所有记录只存在**这台设备的浏览器**里，不上传任何服务器。

首页底部「数据与设置」里可以导出备份（一个 JSON 文件），换设备时导入恢复。

> iPhone 上注意：把网页「添加到主屏幕」后，桌面图标和 Safari 里的记录是**分开存的**。
> 请固定用一种方式打开，别混着用。

## 已知限制

1. **选择填空题是 AI 生成、未经教师审核。** 答案建议家长扫一眼再给孩子用。
2. **解答题是自编的**，已逐题核算过答案，但同样建议家长先看一遍解题过程。
3. **每个知识点 4–5 道客观题**，连续做十几张卷后会开始重复。
4. **根因推断是假设**，不是结论。必须靠下一张卷验证，别直接当成诊断书。
5. **手机卷只出客观题**。解答题要写过程，请走打印流程。
6. **教材目录与课标正文**在源数据里大量标「待核」，尤其 2024 年新教材改版后。
